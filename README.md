# 📝 Next.js Todo App

A modern and interactive Todo application built with **Next.js (App Router)** and **React**.  
It supports task management, user switching, filtering, time tracking, and local storage persistence.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit tasks
- ❌ Delete tasks
- ✅ Mark tasks as completed / active
- 👤 Multi-user task ownership (You, Guest, Work)
- ⏱️ Live time tracking for each task
- 🔍 Filter tasks (All / Active / Completed)
- 💾 Persistent storage using `localStorage`
- 🎨 Modern UI with TailwindCSS + DaisyUI<img width="1920" height="1080" alt="appimg" src="https://github.com/user-attachments/assets/f7a861be-7ee1-465f-88e2-2eaacaa7aea6" />


## 🛠️ Tech Stack

- Next.js 13+ (App Router)
- React Hooks
- Tailwind CSS
- DaisyUI
- LocalStorage API
